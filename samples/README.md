# ActionPilot Sample Scenarios

This directory contains real-world meeting notes and incident response briefs for evaluating ActionPilot's evidence-backed task extraction, AI conflict resolution, and multi-channel action dispatching.

## Scenario Files

1. **`meeting_notes.txt` (Product Launch Sync)**
   - Demonstrates contradictory deadline handling (Nov 2 vs Nov 6 client update for Priya).
   - Demonstrates assignee extraction and support FAQ publication.

2. **`security_incident_response.txt` (Sev-1 DB Incident Brief)**
   - Demonstrates urgent priority handling and moved-up deadlines (Oct 24 vs Oct 23 credential rotation).
   - Demonstrates SOC notification and VPC audit action items.

3. **`q4_strategy_offsite.txt` (Executive Strategy & Budget Alignment)**
   - Demonstrates revised board committee deadlines (Nov 12 vs Nov 18 for FY27 budget model).

4. **`hinglish_voice_memo.txt` (Multilingual Voice Notes)**
